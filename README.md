# rag_chatbot

**OBJECTIVE:**
This project implements a Retrieval-Augmented Generation (RAG) pipeline for efficient document processing and knowledge retrieval. It extracts text and tables from PDFs, stores raw PDFs in In-memory DB, and indexes extracted embeddings in ChromaDB for semantic search. The system leverages MultiVector Retriever for context retrieval before querying an LLM.
